`npm start` now uses a timeout of **10000 ms (10 seconds)**. I ran it, and it printed `timeout=10000`.

Changing the default in `src/config.ts` wasn't enough. The `start` script runs `node --env-file=.env`, and `.env` set `SHOP_TIMEOUT_MS=5000`, which overrides the code default. I changed that value to `10000` as well.

If `.env` is missing or doesn't set `SHOP_TIMEOUT_MS`, the app falls back to the new 10-second default from `src/config.ts`.

I didn't run `npm test`.
