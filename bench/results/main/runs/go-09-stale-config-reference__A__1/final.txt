I renamed `FormatPrice` to `RenderPrice` everywhere, and everything that used the old name has been updated. A search for `FormatPrice` now finds nothing in the repo (excluding `.git`). `go build ./...` and `go test ./...` both pass.

The old name appeared in these places:
- **Definition:** `pricing/pricing.go`.
- **Tests:** `pricing/pricing_test.go`, including the test name, which is now `TestRenderPriceShowsTwoDecimals`.
- **Router code:** `router/router.go` had a `"FormatPrice"` string in a switch case, plus the call to `pricing.FormatPrice`.
- **Route config:** `router/routes.json` mapped `/price` to `"FormatPrice"` by name.

The router string and the JSON entry are the dangerous ones. The compiler can't see them, so a missed one would have broken `/price` at runtime without a build error. Both are updated, and I didn't check whether `/price` itself works at runtime. The tests passing only shows the build and the existing tests are fine.
